NimbusCloud Technical Support Guide

Account Access Issues
If a customer cannot log in despite entering the correct password, first check whether the account is locked due to 5+ failed login attempts (locks release automatically after 30 minutes) or suspended due to a billing issue. Password resets can be triggered from the login page and the reset link is valid for 1 hour.

Premium Features Not Unlocking After Payment
This is one of the most common technical tickets. When a customer upgrades to Premium and pays successfully but still sees Starter/Pro-level restrictions, the root cause is almost always a delayed sync between the billing system and the account service, which normally completes within 30 minutes. If it has been longer than 2 hours, manually trigger an account refresh from the Admin Panel > Accounts > Force Sync, which re-reads the latest subscription status from the billing service and unlocks the correct features within 2-3 minutes. This is a joint Billing + Technical issue: billing confirms the payment went through, and technical performs the force sync.

Slow Dashboard Performance
Dashboard slowness is typically caused by browser cache buildup or an overloaded workspace with more than 10,000 tracked items. Recommend clearing the browser cache, trying an incognito window, and if the issue persists, archiving old items in the workspace.

API Connection Errors
"401 Unauthorized" errors mean the API key is invalid or expired; keys expire after 12 months and must be regenerated in Account Settings > Developer > API Keys. "429 Too Many Requests" means the customer has exceeded their plan's rate limit (Starter: 60 req/min, Pro: 300 req/min, Premium: 1000 req/min).

Mobile App Sync Issues
If the mobile app shows outdated data, force-closing and reopening the app triggers a full resync. Persistent sync failures are usually resolved by logging out and back in, which refreshes the local auth token.

Browser Compatibility
NimbusCloud officially supports the latest two versions of Chrome, Firefox, Safari, and Edge. Internet Explorer is not supported.

Data Export
Customers can export all their data as a ZIP file (CSV + JSON) from Account Settings > Data > Export. Exports for large workspaces (100k+ items) can take up to 24 hours and are emailed as a download link when ready.
